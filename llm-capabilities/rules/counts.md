# Counts in prose

- Do not state the size of a collection when another source owns its members.
- Refer to the collection, or name only the members that matter to the explanation.
- Write `the React apps share source packages`, not `the repository contains two React apps`.
- Write `each app has its own AGENTS.md`, not `both apps have their own AGENTS.md`.
- Do not replace an exact count with `both`, `multiple`, `several`, or another quantity word.
- Use a count only when the quantity is necessary to understand the fact or decide an action.
- Permitted counts include formulas, measurements, limits, thresholds, invariants, and requested results.
- A version, identifier, path, or instruction label is not a collection count.
- Remove the count if membership can change without a change to the described behavior.
- Apply this rule to replies, documents, comments, names, commit text, and GitHub text.
- This rule prevents unnecessary file changes. It also reduces review work, token use, and energy use.
